Напрямую общался с заказчиком, проектировал технические решения, декомпозировал эпики на задачи, объяснял их команде и сопровождал реализацию. Проводил ревью всех изменений команды и координировал релизы.

Наряду с ведением команды разрабатывал алгоритмы демпинга цен и синхронизацию данных с маркетплейсом. Одной из ключевых инженерных задач было поддержание актуальности и согласованности товаров и цен: устаревшие данные или ошибки синхронизации могли привести к некорректным изменениям в магазинах клиентов.

Также разрабатывал API и фоновые задачи для интеграций с каталогами, аналитики и биллинга. Работал с хранением и аналитикой в PostgreSQL и ClickHouse, подбором атрибутов и категорий товаров через LLM.
